## Хранение и права

Каждый тенант имеет отдельную таблицу `steel_grades`. Эффективные значения — база плюс явные overrides, включая `null`. `reset_fields` удаляет выбранную правку и возвращает базовое значение. Проверки и источники отдельных свойств содержат серверные автора/время; изменение значения/источника снимает проверку. Нельзя проверить пустое свойство или таблицу без точек. Member читает; owner/admin создают и меняют. Архив обратим; физического удаления нет. Уникальны действующие наименования без учёта регистра.

Числа поддерживают десятичную запятую; ноль, пустота и «не применимо» различаются. Состав задаётся по химическому символу, min/max в % масс.; проверяются символ, повторы, диапазон 0…100, min≤max и сумма минимумов≤100. Таблица напряжений содержит источники с устойчивыми ключами и точки по температуре в °C, значения в МПа. Повторы температур, неизвестные колонки и отрицательные напряжения запрещены. Частичная таблица с источником и без точек разрешена, проверка такой таблицы — нет.

Исторические противоречия диапазонов базы отображаются предупреждениями. Новая правка диапазона должна быть согласованной. J/X̄-факторы не исправлялись: вопрос остаётся в BACKLOG. Историческое `rbi.matcost` сохранено только для происхождения; оно недоступно на запись и не является принятым коэффициентом. Серверная таблица 4.16 и принятый коэффициент подключены: карточка читает значение и версии источника, ручная правка выполняется только в справочнике. См. [material-costs.md](material-costs.md).

## API

`GET /api/steel-grades/schema`, список с q/status/origin/page/per_page, POST создания, GET/PATCH UUID, GET UUID/events. Сохранение версии и аудит выполняются в одной транзакции с блокировкой; устаревший запрос получает 409. История показывает точные изменённые ячейки состава и напряжений, источники/проверки и архивирование.

Scramble формирует типы запросов/ответов; DTO frontend генерируются из снимка. API выдаёт исходные точки: интерполяция, экстраполяция и нормативный расчёт напряжений не выполняются. Это отдельная задача потребителя с версией источника.
