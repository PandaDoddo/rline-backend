## Данные и происхождение

104 записи перенесены из исходного `frontend/src/mock/data/chemcat.js` в версионированный `resources/catalogs/substances.json`. Версия содержит хеш исходного файла; сохранены исходные значения, ссылки и флаги расхождений. Это перенос существующего набора, а не новая проверка нормативных источников. Локальные правки из браузера не импортируются. Повторная загрузка базы не переписывает tenant-правки, проверки или архив.

`base_values` неизменны; эффективное свойство = tenant-override, если ключ существует, иначе база. Явное `null` очищает свойство, `reset_fields` удаляет override и возвращает базу. Ноль, `false`, неизвестное значение и текст «не установлено» различаются. Числа имеют единицы и диапазоны; ввод запятой поддержан. Справочный состав смеси пока только читается. Поле `grpRFNote` удалено из импорта и запрещено на запись: пояснение группы формируется сервером.

Типизированные свойства: описание/CAS/ICSC, физические показатели и значения четырёх источников, группа РФ и класс/ПДК, критерии API 581, NFPA, репрезентативная среда и примечания/ссылки. Источник и условия могут задаваться для каждого свойства; автор и время назначаются сервером. Проверка закрепляет автора/время; изменение значения или источника снимает её. Проверять пустое значение нельзя; ноль и «нет» проверять можно.

Классификация выдаёт пояснение и предупреждения о несовпадении класса, ПДК и группы. Значения автоматически не исправляются. Интервал между 1,0 и 1,1 мг/м³ не заполняется догадкой. Сохранённые расхождения исходного каталога видны до явной проверки.

## API и интерфейс

- `GET /api/substances/schema` — поля/типы/единицы/допустимая пустота.
- `GET /api/substances` — поиск по имени, формуле, CAS и международным наименованиям; статус, источник, группа, критерий и его да/нет/не задано; постраничная выдача.
- `POST /api/substances` — пользовательское вещество; обязательное имя, остальное пусто.
- `GET/PATCH /api/substances/{uuid}` — карточка и sparse-правки. Обязательная версия, блокировка строки, 409 при устаревшей версии; аудит атомарен с сохранением.
- `GET /api/substances/{uuid}/events` — постраничные изменения значений, источников/условий, проверок и состояния.

Scramble формирует запросы/ответы; frontend использует сгенерированные DTO. Адаптер `features/substances` сохраняет исходную ChemicalCatalogPage и VirtualCatalogList. Нет резервного чтения моков при ошибке. Черновик остаётся при 409 и ошибке; переходы требуют сохранения/отмены. В stories внедряется отдельный клиент с демонстрационными данными.

## Проверки и остаток

`SubstancesTest` покрывает tenant-изоляцию, идемпотентную базу, reset/проверки, права, валидацию и архив. `npm run test:substances` проверяет нормализацию значений, `npm run test:substances:browser` — виртуализацию, сохранение/reset, переходы, member/409 и пусто/ошибку.

Остаются: явный импорт/предпросмотр browser-overrides, обновление базового набора с разрешением конфликтов, редактируемые составы смесей, связи с технологическими потоками и версионированными снимками расчётов. Спорные нормативные значения требуют предметной приёмки; перенос базы не закрывает эти задачи.
