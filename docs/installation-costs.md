# Удельные затраты установки

Срез 07.11.2026: F03.04 подключена к tenant-PostgreSQL и вкладке прежней карточки React. Это входные данные для следующих расчётов CoF; сами финансовые последствия, снимки входов и признаки устаревания сохранённых расчётов ещё не подключены.

## Данные

Миграция 000058 (10.11) переносит текущие входы в InstallationCostParameters: семь численных и три ссылочных параметра с SQL-границами. InstallationCostAnnotations хранит наличие значения, источники и проверки с FK на установку/известное поле. InstallationCostProjection собирает прежние cost_values/cost_sources/cost_checks для API; изменяемые JSON-колонки удалены. Начальные значения пустые, ноль и явно очищенный null отличаются от отсутствующего ключа. Пять численных параметров — envcost (руб/м³), injcost (руб), popdens (чел/м²), prodcost (руб/сут), equipcost (руб/м²). Дополнительно — costfactor и outagemult, системы detsys/isosys/mitsys. Явный 0 сохраняется; очистка даёт null. Только два множителя при отсутствии значения применяются как 1. Остальные пропуски не заменяются нулями.

Числа неотрицательные, не более 10¹⁵; десятичная запятая и пробелы принимаются. Источник и комментарий — до 4000 символов. Источник выбора системы фиксирован: API 581, табл. 4.5 / 4.10. Det/iso хранят номера исходных строк (1–3 / 4–6); mitigation — номер 1–4 или `none` (явно нет системы). Пустая система не означает «нет» и не даёт нулевой коэффициент.

Для каждого свойства есть отдельная проверка с автором/временем. Нулевое значение проверить можно, пустое — нельзя. Изменение значения/источника снимает проверку; повторная запись того же численного значения её не снимает. В интерфейсе проверенное свойство заблокировано до снятия отметки.

## Производные значения

Исходные таблицы перенесены из `ditbl.js` и `cofdata.js` в версионированный снимок `resources/catalogs/installation-cost-tables.json`. Перенесены все девять адаптированных сочетаний: классы A/B/C → fact_di и ld_max d1…d4, четыре системы смягчения → factmit. Дополнения BA/CA/CB явно отмечаются. Производные значения read-only и вычисляются по сохранённому выбору; API не принимает их на запись. Редактор версий этих таблиц в F07 ещё не подключён; локальные правки остальных справочников не изменяют этот серверный снимок.

Плотность из паспорта — stShift/area и stAll/area. Нулевая численность даёт 0; пустая или нулевая площадь не даёт результата. Кнопка «Применить плотность по смене» явно переносит значение и источник в черновик. Изменение площади/персонала обновляет подсказку, но не перезаписывает принятый popdens.

## API и целостность

- GET `/api/installation-costs/schema`: поля, исходные таблицы, версия.
- GET/PATCH `/api/installations/{uuid}/costs`: значения, источники/проверки и производные коэффициенты.
- GET `/api/installations/{uuid}/costs/events`: последние 200 сохранений, по 30 на страницу, с автором и before→after; полный аудит сохраняется.

Запись разрешена owner/admin, member читает. PATCH разреженный и требует общую `version` установки. Паспорт и затраты блокируют одну строку; конкурентная правка паспорта вызывает 409 и сохраняет черновик затрат. Сохранение затрат обновляет версию паспорта в React. Данные другого тенанта недоступны. Источники получают автора/время сервера, служебные поля клиента не принимаются.

## Проверка

PostgreSQL: sparse-правки, 0/null, единицы и числовые диапазоны, источники/проверки, девять сочетаний систем, все коэффициенты смягчения, общая версия/409, роли и изоляция. Storybook: пустая карточка, member, loading/error/conflict; интеграция в карточку установки. `npm run test:installation-costs:browser` проверяет сохранение, применение плотности, историю и guards переключения вкладки/обновления списка.

В F03 остаются ремонты/остановы, архив/удаление, готовность и блокировка шагов, импорт и зависимости сохранённых расчётов. Полная F03 не объявляется завершённой.

## Общая запись и импорт (10.11.2026)

InstallationCostInputValidation использует один контракт HTTP/импорта, включая десятичную запятую и неразрывные пробелы. InstallationCosts отвечает за блокировку установки, общую версию, смену проверок и аудит; контроллер делегирует запись. InstallationCostRepository сохраняет типизированные параметры и аннотации в той же транзакции.

DataExchange принимает installations[].costs (values и необязательные sources) и evidence. Текущие проверки не импортируются из old: source cchk/chk сохраняются только в неизменяемом свидетельстве набора. Адаптер old сопоставляет полное исходное наименование системы смягчения с конкретным номером справочника; неизвестное название останавливает подготовку. Для КС-2 перенесены восемь исходных параметров. Отсутствующие множители не материализуются как 1.

Миграция сравнивает проекцию с исходными объектами перед удалением JSON и откатывает DDL при неизвестных ключах/расхождении. Отложенные SQL-ограничения запрещают скрытые численные значения и проверку неизвестного поля. Проверены перенос/обратный перенос, ошибочная последующая установка, атомарность, безопасный повтор после ручного изменения и ограничения непосредственной SQL-записи. Состояние применения локальной миграции см. в docs/RESUME.md основного репозитория.
