# Стоимость материалов: 4.16 и принятый matcost

Срез 07.11.2026. Два раздела прежнего справочника подключены к PostgreSQL и React. Остальные справочники сохраняют прежний интерфейс; их серверный перенос ещё не завершён.

## Таблица 4.16

Исходник — `frontend/src/domain/calculations/fincost.js`, массив `__FC416M`: 40 исходных строк и дополнение «Низколегированная сталь». Снимок `resources/catalogs/material-costs.json` имеет SHA-версию. UUID строки зависит от исходного английского обозначения, правка русского имени не меняет связи. Английская и русская версии читают один коэффициент; дополнение отсутствует в английской версии.

`GET /api/references/material-costs` возвращает 41 строку. `PATCH /api/references/material-costs/{uuid}` принимает версию строки и разреженные `values.name/factor`, `sources`, `verification`, `reset_fields`. Действующие значения отделены от неизменяемой базы; очистка коэффициента сохраняет `null`, сброс удаляет правку. Коэффициент — положительное конечное число до 1 000 000. Группа, английское обозначение и версия базы не редактируются; строки не удаляются.

`GET /api/references/material-costs/{uuid}/events` — история последних 200 событий, по 30 на страницу; в полном аудите события не удаляются. Автор разрешается только среди участников текущего тенанта. Пишут owner/admin, member читает. Устаревшая версия даёт 409, черновик интерфейса сохраняется. Источник и значение при изменении снимают проверку; пустой коэффициент проверить нельзя.

Калькулятор использует `base + Σ(k − 1)` по выбранным слоям. Пустой коэффициент не заменяется единицей. Калькулятор не создаёт сохранённый расчёт CoF.

## Принятый коэффициент марки

`GET /api/references/steel-costs` читает действующие марки и таблицу 4.16 в одном REPEATABLE READ-снимке, без запросов на каждую марку. `SteelMaterialCost` переносит прежнее правило выбора аналога по подтипу/уточнению и Cr/Mo/Ni. Использует эффективный состав марки, включая tenant-правки. Неизвестный подтип или очищенный коэффициент даёт `null`. Исторический `rbi_matcost` не используется.

Отсутствующий элемент при выборе аналога трактуется как 0 по прежнему правилу, но возвращается явное допущение и предупреждение; исходный состав не дополняется. При неточном аналоге (309/310, дуплексная, ферритная 430/446) также есть предупреждение. Предметная проверка исходных составов остаётся отдельной задачей из BACKLOG.

`PATCH /api/references/steel-costs/{uuid}` принимает общую версию марки и `values.accepted_cost/cost_reason`, источники, проверки и сброс. Ручной коэффициент имеет приоритет над автоматическим; явный `null` остаётся отсутствием данных. Сброс `accepted_cost` возвращает выбор по таблице. Проверка автоматического значения в интерфейсе явно сохраняет его как принятый коэффициент. История общая с маркой, поэтому конкурентная правка состава также вызывает 409.

В карточке марки принятую стоимость менять нельзя: поля защищены основным API марочника. `assessment` возвращает принятый и автоматический коэффициенты, признак ручной правки, аналог, обоснование, допущения, UUID и версии исходной строки. Изменение таблицы меняет автоматический коэффициент, но сохраняет принятый вручную.
