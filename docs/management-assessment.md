# Оценка систем управления

Анкета API 581 хранит ответы в `ManagementAnswer`, варианты множественного выбора — в `ManagementSelection`. Дата оценки, имя аудитора и общий комментарий — `ManagementDetails` (000059), с FK владельца для ответов. Новая шапка не подставляет дату, аудитора или итоговую оценку из текущего пользователя/сегодняшнего дня. Все вкладки установки сохраняют общую оптимистическую версию.

`ManagementInputValidation` — общий структурный контракт HTTP и обмена; `InstallationManagement` проверяет версию анкеты, допустимые значения каждого вопроса, обоснование NA и сохраняет изменения/аудит в одной транзакции. Чтение API — согласованный read-only снимок. Контракт ответа допускает boolean, число, список индексов или null; Scramble описывает этот union через отдельный трансформер. Дата/аудитор/комментарий редактируются в React; Storybook и браузер проверяют сохранение, очистку, конфликты, права и узкий экран.

В `rline-dataset-v1` установка принимает `management` (schema_version, answers, details). Адаптер `frontend/tools/legacy-parity/management-inputs.mjs` читает только сохранённые ответы old. Отсутствие ответа не превращается в «нет». False, нулевые оценки и явно выбранный нулевой вариант сохраняются. Старые дата/аудитор переносятся в шапку; `chk`, история и исходные NA сохраняются свидетельством, без фиктивной текущей проверки.

В old КС-2 есть 122 ответа; **1.4, 2.4, 5.22 и 5.23** отмечены NA без обоснования. Для текущей методики это незавершённые ответы (`unanswered`), исходные флаги/значения сохранены в evidence и замечаниях. Обоснования не генерируются. Оценка/Fms для принятого PoF не выдаются, пока необходимые ответы не уточнены; предварительные показатели явно остаются предварительными. Не подменять их старым сохранённым результатом.

Локальный preview old-full-demo-v5 (122 ответа, восемь затрат, 62 вещества, 79 узлов, четыре ЕО со всеми контактами) прошёл с откатом: 37 замечаний, 0 исходных ошибок в этом поднаборе. Полный манифест на 241 ЕО содержит 767 замечаний и прежние 20 исходных ошибок давлений; полный preview этой версии ещё не повторялся. Рабочая БД rline не наполнена. Проверки API/импорта/анкеты: 36 тестов / 3323 assertions; шапка/контракт отдельно 5 / 485. Миграция 000059 применена локально после дампа, публичный сервер не обновлялся.

000060 связывает исходные замечания с установкой и показывает их в API/React. Баннер происхождения доступен анкете и затратам, предупреждение у вопроса — пока ответ незавершён; исправление не стирает исходное свидетельство. Список ограничен 200 элементами с явным source_issues_truncated. Следующие части: остальные владельцы old и сохраняемые RBI-запуски. История old остаётся отдельным свидетельством и не имитирует события текущей системы.
