# Журнал изменений backend

## 06.11.2026 — Отдельный репозиторий backend
- Laravel 13 / PHP 8.5, Docker Compose, PostgreSQL 18, Nginx и worker подготовлены для публикации в PandaDoddo/rline-backend.
- Включены аутентификация Sanctum/Fortify, TOTP, LDAP/AD/Multifactor, тенанты с отдельными БД/ролями и настройки провайдеров по организации.
- Документация авторизации, тенантов и архитектуры включена в репозиторий; ссылки на frontend переведены в основной репозиторий.

- Следующие этапы — предметные API, полная матрица прав, приглашения и приёмка внешних провайдеров на реальных серверах.
